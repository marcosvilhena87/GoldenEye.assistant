# Configuração local

`assistant.lua` permanece desabilitado. `mapping_snapshot.lua` é um arquivo gerado localmente pelo exportador e está ignorado pelo Git.

**Não habilite acesso à memória só porque um símbolo possui `validated`.** Ainda é necessária a verificação real da ROM carregada, do emulador, do domínio e da condição de validade por um adaptador específico.

Nunca copie valores de endereço para este diretório.
